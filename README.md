# ZB_heatwave：指定经纬度热浪事件识别

本项目包含 6 个可独立运行的 Python 脚本，用于从逐日地表温度或体感温度栅格中读取指定经纬度所在像元，识别热浪事件并输出事件表。

## 脚本与默认方案

文件名中，`LST` 表示地表温度，`AT` 表示体感温度；
`ATT` 对应固定温度阈值，`CRTT+ATT` 对应气候逐日阈值与固定阈值同时满足，`ARTT+ATT` 对应逐年阈值与固定阈值同时满足。

| 脚本 | 温度指标 | 高温日判据 | 默认方案 |
| --- | --- | --- | --- |
| [LST_ATT.py](LST_ATT.py) | 地表温度 | 达到固定阈值 | 45 ℃，至少 3 天 |
| [LST_CRTT+ATT.py](LST_CRTT+ATT.py) | 地表温度 | 同时达到固定阈值与气候逐日百分位阈值 | 45 ℃，第 90/95 百分位，至少 3 天 |
| [LST_ARTT+ATT.py](LST_ARTT+ATT.py) | 地表温度 | 同时达到固定阈值与当年百分位阈值 | 45 ℃，第 80/85 百分位，至少 3 天 |
| [AT_ATT.py](AT_ATT.py) | 体感温度 | 达到固定阈值 | 29 ℃，至少 3 天 |
| [AT_CRTT+ATT.py](AT_CRTT+ATT.py) | 体感温度 | 同时达到固定阈值与气候逐日百分位阈值 | 29 ℃，第 90/95 百分位，至少 3 天 |
| [AT_ARTT+ATT.py](AT_ARTT+ATT.py) | 体感温度 | 同时达到固定阈值与当年百分位阈值 | 29 ℃，第 80/85 百分位，至少 3 天 |

## 运行方法

1. 准备逐日栅格，安装数值计算库 `numpy` 和地理空间数据抽象库 GDAL 的 Python 绑定（`osgeo`）。
2. 根据温度指标和判定方案选择脚本，打开末尾的“用户参数”区域。
3. 填写输入、输出路径以及实际经纬度，核对年份、阈值和温度单位。
4. 在 Python 环境中运行。

## 运行参数与输入目录

在脚本末尾修改以下参数。示例目录与坐标仅演示填写格式，须替换为实际值：

```python
INPUT_FOLDER = r""#温度文件夹路径
OUTPUT_FOLDER = r""#结果文件夹路径
LONGITUDE = 70.0  # 替换为实际目标经度
LATITUDE = 30.0   # 替换为实际目标纬度
START_YEAR = 2003
END_YEAR = 2024
TEMP_THRESHOLD = 45.0
DURATION_THRESHOLD = 3
```

坐标使用 WGS84 十进制度，经度在前、纬度在后。输入输出路径和坐标默认未填写，须显式设置；
体感温度脚本的默认年份为 1980—2024 年、固定阈值为 29 ℃。

地表温度影像须按四位年份设置一级子目录：

```text
地表温度/
    2003/
        20030101.tif
        20030102.tif
    2004/
        20040101.tif
```

体感温度影像直接放在输入目录中，不设置年份子目录：

```text
体感温度/
    19800101.tif
    19800102.tif
    20200601.tif
```

- 地表温度用 `VALUE_SCALE`、`VALUE_OFFSET` 进行“原始值 × 缩放系数 + 偏移量”换算，默认分别为 `0.1` 和 `0.0`。输入已为摄氏度时应核对并调整缩放系数；脚本不自动应用影像缩放或偏移元数据。
- `INPUT_NODATA = -32768` 是地表温度的备用原始缺测编码，在温度换算前剔除；两类脚本同时检查影像自身缺测值、有效掩膜和非有限数值。体感温度必须已经是摄氏度，脚本不从其他气象变量计算体感温度。
- `CRTT+ATT` 与 `ARTT+ATT` 默认 `METHOD = "relative"`，须同时满足固定与相对阈值；改为 `"absolute"` 时只计算一次固定阈值方案。
- `PERCENTILES = (90, 95)` 分别计算两组气候逐日方案，`(80, 85)` 分别计算两组逐年方案。单组可写 `(90,)` 或 `(80,)`。
- 地表温度 `CRTT+ATT` 的 `BASELINE_START_YEAR`、`BASELINE_END_YEAR` 可独立于输出期设置，两者均为 `None` 时采用全部输入年份。体感温度 `CRTT+ATT` 没有独立基准期参数，输入目录全部年份都参与计算。
- 地表温度的 `ALLOW_MISSING_LEAP_DAY = True` 默认允许跨缺失闰日连接，但时长只计实际高温影像日。严格日历连续须设为 `False`，并在 `CRTT+ATT` 中保持 `BREAK_ON_DATE_GAP = True`；若后者为 `False`，可按影像序号跨普通缺日连接。体感温度始终严格按日历连续。

## 百分位阈值的计算

气候逐日阈值（CRTT）使用基准期内同一像元、同一气候日跨年的有效温度样本计算，不使用滑动日期窗口。2 月 29 日样本并入 2 月 28 日，两天共用阈值。某气候日没有有效样本时，该日不判为高温日，不回退到仅使用固定阈值。该阈值以单精度浮点数存储；体感温度版本再以双精度进行判定，地表温度版本保留既有温度与阈值比较方式。

逐年阈值（ARTT）分别使用每一年该像元全部有效日温度计算，闰日存在且有效时参与。体感温度版本保留百分位函数返回的阈值精度，不降为单精度。

程序读取包含输入坐标的第一波段像元，不做空间插值。控制台会显示从零开始的行列号和像元中心坐标；坐标越界、投影缺失或网格不一致会报错。仅读取单像元窗口。

## 输入与结果

输入文件名为合法八位年月日，例如 `20200601.tif`。
各参与计算的影像须有有效坐标系，并保持一致的网格、空间范围和波段含义。
```csv
start_date,end_date,duration_days
2020-06-01,2020-06-03,3
```
上述内容为输出结果格式示例。三列依次为开始日期、结束日期、持续天数。
结果使用带字节顺序标记的 UTF-8 编码，方便电子表格软件读取；无事件时保留表头。结果文件名包含方案、阈值、经纬度与年份范围。

## 需要区分的计算口径

- 两类温度均使用大于或等于阈值的判据，事件按年拆分，跨年片段分别满足最短持续时间才输出。
- 地表温度默认按原始值乘以 `0.1` 换算为摄氏度；体感温度要求输入已为摄氏度。
- 地表温度默认允许在缺失 2 月 29 日文件时连接 2 月 28 日与 3 月 1 日，但时长只计实际高温影像日。体感温度要求严格日历连续，任何缺日均中断。
- 地表温度的气候逐日阈值可单独指定基准期，默认 2003—2024 年。
- 固定阈值以外的两类方案仍须同时满足固定温度阈值，并非仅按百分位判定。
- 缺测值、无效掩膜和非有限数值不作为高温日，脚本不会自动补齐缺测影像。
